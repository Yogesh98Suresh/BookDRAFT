# YBook – Book Management / Social Web Project

YBook is a frontend web project built using **HTML, CSS, and JavaScript**. The project focuses on creating an interactive and user-friendly web interface with responsive styling and JavaScript-based functionality.

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

### ✨ Features

* Clean and simple user interface
* Responsive webpage layout
* Interactive elements using JavaScript
* Structured HTML components
* Custom CSS styling and navigation

### 🎯 Purpose

This project was created to practice and strengthen frontend development skills, particularly **HTML structure, CSS styling, JavaScript DOM manipulation, and responsive design**.
